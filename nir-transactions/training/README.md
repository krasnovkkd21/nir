# Обучение моделей

Команды выполняются из корня проекта. Для применения опубликованных весов обучение можно пропустить.

## Классификатор XGBoost

Один набор клиентов используется для обучения на периоде P2. Другой даёт операции P3 для выбора числа деревьев и настройки двух порогов. Скрипт делит клиентов P3 пополам детерминированно по хешу идентификатора. Для вычисления метки первой операции он проверяет весь мошеннический эпизод, в том числе его начало в предыдущем периоде. Метки и идентификаторы служат для обучения и сопоставления строк. В матрицу признаков входят только 188 столбцов из опубликованной схемы.

Для небольшого самостоятельного запуска можно сгенерировать две группы, например по 500 клиентов.

```sh
python features.py generate --clients 500 --seed 101 --output-dir data/train
python features.py generate --clients 500 --seed 202 --output-dir data/dev
python features.py build --period 2 --data-dir data/train --output-dir data/train_p2
python features.py build --period 3 --data-dir data/dev --output-dir data/dev_p3
python training/fit_classifier.py --train data/train_p2 data/train --development data/dev_p3 data/dev --output-dir runs/refit
python predict.py data/dev_p3 runs/refit-dev.parquet --model-dir runs/refit
```

Этот пример демонстрирует запуск и решения на данных разработки. Для независимой оценки нужны другие клиенты и период P4. Каждая пара после `--train` задаёт каталог признаков и соответствующий каталог исходных операций с разметкой. Параметр можно повторить для нескольких обучающих групп. Программа принимает также архивные кэши с `config.json`, `X.npy` и `ids.npy` при наличии соответствующих исходных данных. При калибровке общего порога допустимая доля тревог среди законных операций равна 0,410522 %, для ручной проверки — 0,1 %.

В опубликованном запуске было пять обучающих групп по 6 000 клиентов с начальными значениями генератора 20261122, 20261201, 20261202, 20261203 и 20261204 (в таком порядке), группа разработки — 20261211. Обучающая матрица P2 содержала 2 600 229 транзакций. Верхний предел составлял 400 деревьев, глубина — 6, скорость обучения — 0,05. Ранняя остановка после 40 раундов без улучшения сохранила 250 деревьев. На группе для остановки приоритет имело число обнаруженных мошеннических операций при заданной доле ложных тревог, затем число обнаруженных первых операций эпизодов и средняя точность ранжирования. Пороги для применения выбирались только по законным операциям второй половины клиентов P3.

## Кодировщик истории операций

Сохранённый Transformer использует скрытый вектор размерности 32, четыре головы внимания и dropout 0,1. Оптимизатор AdamW работал со скоростью обучения 0,0003 и коэффициентом затухания весов 0,01. Размер пакета составлял 256, начальное значение генератора обучения — 42. В каждой эпохе на одну мошенническую операцию случайно отбирали до 64 законных. Обучение ограничивали 40 эпохами и останавливали после шести эпох без улучшения.

`training/fit_encoder.py` содержит исходную процедуру обучения Transformer. Чтобы повторить обучение отдельно, нужны подготовленные признаки одной группы за все периоды и её размеченные операции. Скрипт берёт из матрицы 54 наблюдаемых поля, использует P0 для накопления истории и делит P1 по времени. Первые две трети P1 идут на обучение, последняя треть — на выбор эпохи по средней точности ранжирования. На вход подаётся окно до 16 операций текущего клиента. В исходном запуске использовалась группа 20261122 из 6 000 клиентов. Обучение остановилось после 29 эпох, сохранены веса 23-й эпохи.

```sh
python features.py build --data-dir data/train --output-dir data/train_all
python -m training.fit_encoder --features data/train_all --data data/train --output-dir runs/new-encoder
python features.py build --period 2 --data-dir data/train --encoder-dir runs/new-encoder --output-dir data/new_train_p2
python features.py build --period 3 --data-dir data/dev --encoder-dir runs/new-encoder --output-dir data/new_dev_p3
python training/fit_classifier.py --train data/new_train_p2 data/train --development data/new_dev_p3 data/dev --output-dir runs/new-classifier
```

Числа в отчёте относятся к сохранённым весам и исходным экспериментальным выборкам. Сокращённые примеры используют другие данные и предназначены для проверки процесса обучения. Для переноса обученной связки на новые операции признаки строят с тем же кодировщиком, с которым обучали XGBoost.
